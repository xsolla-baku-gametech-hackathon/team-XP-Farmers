# Demo audio

These three WAV files are synthesized by `tools/generate_demo_audio.cjs` from
oscillators and note sequences. No external recordings or sample libraries are
used. Regenerate them with Node.js; Node is not required to play the Godot project.

- **Neon Run:** energetic normal-mode demo loop.
- **Quiet Orbit:** slower replacement demo loop.
- **Collect:** short gameplay feedback sound.

Both music tracks are demo material. Neon Run is not deliberately infringing
music; the toggle demonstrates replacement without putting a third-party song in
the demo. For production, developers must select tracks with appropriate rights.
These assets do not imply a guarantee against platform copyright claims.
